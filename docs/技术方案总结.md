## 四部分代码的定位与关系

```
vendor/unigoal (原始 UniGoal 场景图)
     ↑ 继承基础架构
lifelong_graph (UniGoal 增强版，重写了 node/edge 逻辑)
     
     ↑ IS-Bench 包装层
unigoal_grounded_sam backend     samjam_unigoal backend
(直接使用 vendor 原始方案)         (使用 lifelong 式方案)
```

---

## 一、相同的基础 pipeline

四者都共享相同的**3D 建图流程**（继承自 `vendor/unigoal` 的 `mapping3d`）：

```
segment2d() → mapping3d() → get_caption() → update_node() → update_edge()
```

- `mapping3d()`：Grounded-SAM 检测 → 点云反投影 → FAISS 空间重叠匹配 → merge 到 `MapObjectList`
- `get_caption()`：mode voting 确定物体类别名

**node 数据结构**完全一致：`ObjectNode(caption, center, edges, room_node, ...)`

---

## 二、核心差异：edge 构建

### vendor/unigoal（原始）—— LLM 猜关系

```python
def update_edge(self):
    # 对所有新边，用 LLM 批量猜关系
    prompt = self.prompt_edge_proposal + '\n({}, {})' * len(new_edges)
    relation_response = self.llm(prompt=prompt)
    # 解析 LLM 输出，匹配预定义关系列表
    for relation in relations:
        relation_type = self._extract_relation_type(relation)
        if relation_type is not None:
            edge.set_relation(relation_type)
        else:
            edge.delete()  # unknown 就删边
```

**特点**：只给物体名对，LLM 靠常识猜，没有几何信息、没有视觉信息。**它无法区分 `(apple, table)` 是 on/above/below**。

---

### lifelong_graph——几何推理为主

这是**最大的改进**。引入了一个关键概念：**物体分类（coarse vs fine）**

| 类别 | 定义 | 例子 |
|---|---|---|
| **coarse** | 大件家具（可附着载体） | table, cabinet, bed, counter, shelf... |
| **fine** | 小物件（被放置的物体） | apple, book, cup, bottle, plate... |

`update_edge()` 的流程完全重写：

```python
def update_edge(self):
    self.refresh_coarse_near_edges()          # ① coarse-coarse: 几何距离→near
    frame_relations = self.build_frame_relations()  # ② fine-coarse + fine-fine
    # ③ 操纵物体边处理
    self.reconcile_manipulated_edges(frame_relation_map)
    # ④ 应用新边
    for node1, node2, relation in frame_relations:
        self.upsert_edge(node1, node2, relation)
    self.refresh_fine_fine_near_edges()       # ⑤ fine-fine near
```

#### ② `build_frame_relations()` 的核心——几何判断

**fine-coarse 关系**（如 `apple on table`）：

```python
def infer_fine_coarse_relation_from_geometry(self, fine_node, coarse_node):
    # 1. 计算 XY 投影重叠率
    fine_cover_ratio, _ = self.compute_xy_overlap_ratio(...)
    
    # 2. 计算 Z 轴间隙 (支持面接触检测)
    top_contact_gap = min(
        abs(fine_min[2] - coarse_max[2]),     # fine 在 coarse 上面
        abs(fine_max[2] - coarse_min[2])      # fine 在 coarse 下面
    )
    
    # 3. 判断 on → XY 接触 + Z 间隙小
    if top_contact_gap <= self.on_gap_thresh and fine_cover_ratio >= ...:
        return 'on'
    
    # 4. 判断 in → XY 完全在内部 + Z 在内部
    if coarse in {cabinet, dresser, refrigerator, ...}
       and fine_xy_inside and fine_z_inside and fine_cover_ratio >= 0.55:
        return 'in'
    
    # 5. 判断 attach to → 侧面靠近 + Z 方向重叠
    if side_gap <= 0.14 and z_overlap / fine_height >= 0.35:
        return 'attach to'
    
    # 6. 判断 above → Z 方向有间距 + XY 接触
    if z_gap >= 0.30 and fine_cover_ratio >= 0.10:
        return 'above'
```

**这就精确区分了 `apple on table` vs `apple above table` vs `apple below table`！**

**fine-fine 关系**（如 `cup near plate`）：

- 共享同一个 coarse parent（都在 `table` 上）
- 表面距离 <= 0.22m → `near`

#### ③ 操纵感知（Manipulation Awareness）

```python
self.manipulated_node_uids  # 记录被机器人拿起的物体
```

物体被拿起后：
- 旧边全部删除（不再 `on table`）
- 放下后在当前帧用**新的几何测量**重新推断关系

### samjam_unigoal backend——继承 lifelong 方案

这是 IS-Bench 对 lifelong_graph 方案的**独立复现**：

```python
def _update_structured_edges(self, frame_relations):
    self._refresh_coarse_near_edges()
    # 几何推理 fine-coarse 关系
    self._infer_fine_coarse_relation(fine_node, coarse_node)  # → on/in/attach to/above
    # 操纵感知处理
    self._reconcile_manipulated_edges(frame_relation_map)
    # fine-fine near
    self._refresh_fine_fine_near_edges()
```

关键区别：
| 方面 | lifelong_graph | samjam_unigoal |
|---|---|---|
| 感知输入 | Grounded-SAM + UniGoal mapping | SAMJAM (SAM v2) + UniGoal mapping |
| 边推理 | 在 `Graph` 类内 | 在 `SAMJAMUniGoalGraphAdapter` 类内 |
| 参数 | 硬编码属性 | 环境变量可配置 |
| VLM 验证 | `infer_relation_from_image()` 调用 | 不使用 VLM |

**边推理逻辑几乎与 lifelong_graph 完全一致**，是它的一个独立移植版。

---

### unigoal_grounded_sam backend——保留 vendor 原始方案

这个 backend **直接使用 vendor/unigoal 的原始 `Graph`**，走完整的 Grounded-SAM 分割路径。它的 `update_edge()` 完全继承 vendor 的 LLM-only 猜关系方案，**没有几何推理**。

## 三、对比总结表

| 方面 | vendor/unigoal | lifelong_graph | samjam_unigoal | unigoal_grounded_sam |
|---|---|---|---|---|
| **node 构建** | ObjectNode | ObjectNode + uid + coarse/fine + is_vis | ObjectNode + uid + coarse/fine + is_vis | ObjectNode（原始） |
| **edge 构建方法** | LLM 常识猜 | **几何推理 + 操纵感知** | **几何推理 + 操纵感知**（同 lifelong） | LLM 常识猜（同 vendor） |
| **区分 on/above/below** | ❌ 不能 | ✅ 3D bbox 计算 | ✅ 3D bbox 计算 | ❌ 不能 |
| **coarse/fine 分类** | ❌ 无 | ✅ 有 | ✅ 有 | ❌ 无 |
| **操纵物体处理** | ❌ 无 | ✅ manipulated_node_uids | ✅ manipulated_node_uids | ❌ 无 |
| **coarse-coarse near** | ❌ 无 | ✅ 几何距离 | ✅ 几何距离 | ❌ 无 |
| **fine-fine near** | ❌ 无 | ✅ 共享 parent + 距离 | ✅ 共享 parent + 距离 | ❌ 无 |
| **VLM 图像验证** | 有（但未启用） | 有（fine-fine 用） | ❌ 不用 | 有（但未启用） |
| **分割方式** | Grounded-SAM | Grounded-SAM | SAMJAM (SAM v2) | Grounded-SAM |

## 四、结论

**lifelong_graph 的 node/edge 构建逻辑与 `samjam_unigoal` 的 `_update_structured_edges()` 体系高度相似**——两者都是**几何推理为主**的方案，通过 coarse/fine 分类、3D bbox 计算、操纵感知来精确判断物体关系。

而 **vendor/unigoal 与 `unigoal_grounded_sam`** 属于原始的 LLM-only 方案。

lifelong_graph 最大的改进是**用几何计算替代了 LLM 常识猜测**，使得 `(apple, table)` 能通过实际的 3D 包围盒重叠和 Z 轴间隙准确判断是 on / in / above / attach to。
